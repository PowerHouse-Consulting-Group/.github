# Open-Source llms.txt Template for HubSpot Ecosystem Partners

Welcome to the PowerHouse Consulting Group community resource repository. This repository contains a standardized, open-source template for deploying an `llms.txt` file to make websites machine-readable for AI crawlers (like GPTBot, ClaudeBot, and Perplexity).

## 📦 What's Inside
* `llms.txt` — The foundational markdown sitemap layout tailored for HubSpot-driven websites.

## ⚙️ How to Deploy This
1. Copy the raw text from the `llms.txt` file in this repository.
2. Customize the bracketed fields `[...]` with your client's specific company data, core values, and service details.
3. Upload the finalized text file directly into the root directory of your client's website server (so it resolves at `https://yourclient.com/llms.txt`).

## 🔄 Resolving the Attribution Blindspot
While this template makes a website legible to AI models, tracking the revenue downstream requires advanced CRM plumbing. Because link clicks from AI applications often mask themselves as "Direct" or "Unknown" traffic inside HubSpot analytics, you must combine this file with explicit parameter tagging and session-persistence scripting.
